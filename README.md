# Java Online Shop

## Overview

The Java Online Shop is a Java application developed to explore the implementation of online shopping functionality. The project applies Java programming concepts to a shop-oriented application.

## Technologies

- Java
- Maven

## Getting Started

### Prerequisites

- Java JDK compatible with the project configuration.
- Maven (optional, as the repository includes a Maven Wrapper).

### Running the Project

1. Clone or download the repository.
2. Open a terminal in the project directory.
3. Build the project using the Maven Wrapper:

   ```bash
   ./mvnw clean package
   ```

   On Windows, use `mvnw.cmd clean package`.

4. Open the project in IntelliJ IDEA and run the main application class, or use the execution configuration defined in the project.

## Learning Outcomes

This project provided practical experience with Java application development, organizing code into a structured project, and applying programming concepts to a shop-oriented application.
